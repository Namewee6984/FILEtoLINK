# Let's your files to web links
We connected several internet pubilc severs for user
# Expiring Time
When the files stored on the server reach the threshold, we may delete your files. At that time, the links you already have will become unavailable.
# Using
You can chick [This](https://cs144.medibot.cc/resources/doc/1792096563304.html) to using.Or you can download [index.html](https://github.com/Namewee6984/FILEtoLINK/blob/main/index.html) To use.
# Notices
We do not offer any storage services.The core functionality is all provided by public internet servers,Usability and security can change without notice.Anyone who gets the link can download the file after it is uploaded.So you should avoid uploading private, confidential, or other non‑public files.
